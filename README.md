## About me

- Software engineer working on backend systems and the LLM infrastructure that sits on top of them
- Operations and platform engineering at **EnginearU LLC** (remote, Charleston SC), where I build an AI-adaptive AP Computer Science learning platform
- Most of my spare cycles go into eval harnesses, agentic tool-calling and retrieval, usually by building the thing myself instead of reading about it
- Happy to talk about LLM evaluation, storage engines, Python internals or teaching code to teenagers

## What I'm building

| Project | What it does | Stack |
| --- | --- | --- |
| [**evalgate**](https://github.com/gafeh/evalgate) | Evaluation harness for LLM graders, with a CI gate that fails a build when grader quality regresses | Python, FastAPI, Postgres |
| [**ember**](https://github.com/gafeh/ember) | HTTP server written from the socket up: request parsing, keep-alive, concurrency, no framework | Python |
| [**talentops**](https://github.com/gafeh/talentops) | Recruiting operations platform, from sourcing through pipeline tracking | TypeScript, Next.js |
| [**rwazi-outbound-engine**](https://github.com/gafeh/rwazi-outbound-engine) | Outbound GTM engine built and shipped for Rwazi: enrichment, scoring, sequencing | Python |
